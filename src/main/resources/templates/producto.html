¿Por qué estas ofertas son «el mismo producto»?

Solo declaramos equivalencia exacta cuando coinciden un código GTIN/EAN o la combinación verificable de marca y modelo. En caso contrario, SAMP las muestra como «similares».

¿Cómo se calcula el total?

Total = precio publicado + envío + impuestos conocidos, convertido a COP con tasa fechada. Si algún costo falta, se muestra como «Desconocido» y nunca como cero.

¿Qué significa «DEMO»?

Indica que la tienda bloqueó el acceso automatizado o no tiene API pública y se está mostrando el catálogo de demostración de respaldo.
